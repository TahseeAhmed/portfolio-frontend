# Tahseen Ahmed - Portfolio Frontend 
 
Personal portfolio website built with React + Vite. 
 
## Tech Stack 
- React 18 
- Vite 
- Tailwind CSS 
 
## Setup 
1. Clone the repo 
2. Run: npm install 
3. Create .env file: VITE_API_URL=http://localhost:5000 
4. Run: npm run dev 
 
## Deployment 
- Frontend: Vercel 
- Backend: Railway 
- Database: MongoDB Atlas
